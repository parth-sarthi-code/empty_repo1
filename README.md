# NLP Lab

Assignments and coursework for Natural Language Processing (CSET346).

## Overview

- **`Assignment_intro/`**: Working with different data formats (text, csv, json, images, audio, video, excel) and basic NLP text preprocessing (cleaning, tokenization, stemming, lemmatization, NER, POS tagging, TF-IDF).
- **`Assignment_01/`**: Brown corpus preprocessing, comparing Porter Stemmer vs WordNet Lemmatizer, spelling correction with edit distance, and N-gram language modeling.
- **`Assignment_02/`**: WordNet exploration, hypernym hierarchies, semantic path similarity, and homonym sense disambiguation.
- **`Assignment_03/`**: Corpus analysis, statistical N-gram modeling, and sequence analysis.
- **`Assignment_04/`**: Part-of-Speech (POS) tagging and sequence labeling.
- **`Assignment_05/`**: Text classification and vectorization techniques (Bag of Words, TF-IDF).
- **`Assignment_06/`**: Word embeddings (Word2Vec CBOW, GloVe), regional/Indic language embeddings, and cross-lingual text retrieval.
